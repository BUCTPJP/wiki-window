# Wiki Window

[中文](#中文) | [English](#english)

## 中文

Wiki Window 是 Minecraft Java 版 1.20.1 的 Forge 客户端模组，可在游戏内搜索中文 Minecraft Wiki，阅读文字摘录、查看词条主图和匹配到的普通工作台配方。

### 安装和使用

1. 安装 Minecraft Java 版 1.20.1、Forge 47 和 Java 17。
2. 将 `ingamewiki-1.0.0.jar` 放入游戏实例的 `mods` 文件夹，移除旧版本。
3. 进入世界，按 **K** 打开界面。输入关键词后搜索，点击结果并使用滚轮阅读；快捷键可在控制设置中更改。
4. 鼠标悬停查看材料名称，点击配方区域可切换多个配方。

### 使用范围

- 需要联网；搜索词发送至中文 Minecraft Wiki。Wiki 内容会更新，可能包含其他游戏版本的信息。
- 正文为纯文本摘录，不支持完整网页排版、正文中其他图片、表格、链接和视频。
- 配方来自当前世界，仅显示普通有序和无序工作台合成；物品名称需与当前游戏语言匹配，烧炼、锻造及特殊配方不在支持范围内。
- 模组不内置中文输入法。可粘贴文本；安装 caramelChat 时使用“搜索”按钮，回车留给输入法。中文候选词输入尚未完成兼容性实测。

## English

Wiki Window is a client-side Forge mod for Minecraft Java Edition 1.20.1. Search the Chinese Minecraft Wiki in-game and read plain-text extracts, view available lead images, and see matching ordinary crafting recipes.

### Installation and use

1. Install Minecraft Java Edition 1.20.1, Forge 47, and Java 17.
2. Place `ingamewiki-1.0.0.jar` in the instance's `mods` folder and remove older versions.
3. Open a world and press **K**. Search for a term, select a result, and scroll to read. The key binding can be changed in Controls.
4. Hover over ingredients for their names and click the recipe area to cycle through recipes.

### Scope

- An internet connection is required and search terms are sent to the Chinese Minecraft Wiki. Wiki information may describe newer game versions.
- Article bodies are plain-text extracts; full page formatting, additional images, tables, links and videos are not supported.
- Recipes come from the current world and cover ordinary shaped and shapeless crafting only. Matching depends on the current game language; smelting, smithing and special recipes are not supported.
- The mod does not include an input method. Paste text if needed. With caramelChat installed, use the Search button and reserve Enter for the IME; Chinese composition has not yet been fully tested.
